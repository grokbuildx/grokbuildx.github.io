gbx

A free, open-source command-line tool for software developers that connects the Grok Build and Codex coding assistants to the model provider of your choice.

This is the official home page of the application gbx, the name shown on its Google sign-in screen. You do not need an account or a sign-in to read this page, download gbx or use it. Signing in with Google is optional and only turns on settings sync (see below).

What gbx does

Grok Build is a coding assistant that runs in a terminal and helps developers read, edit and test source code. gbx starts Grok Build for you, adds models to the Codex model picker, and connects them to the model service you choose:

  • OpenAI-compatible APIs and gateways, with your own API key, by translating requests on your computer through a local proxy bound to 127.0.0.1;
  • coding subscriptions you already have, after you sign in to them.

gbx keeps several saved provider configurations, switches between them, and can run Grok Build sessions in your local browser with gbx serve.

gbx is a tool for writing software. It works only with text and source code. It does not create, edit or process images, video or audio.

gbx runs entirely on your own computer. Its developers run no servers, collect no data and have no user accounts. The full source code is public under the MIT License.

Install

npm install -g @grokbuildx/gbx   # needs Node.js 22 or later
gbx set                               # add a model provider
gbx                                   # start Grok Build with it

Downloads, documentation and release notes: github.com/grokbuildx/gbx.

How gbx uses Google user data

gbx uses Google for one optional feature: syncing gbx's own settings between your computers. When you run gbx cloud login and choose Google Drive, gbx opens Google's sign-in page in your browser and asks for one permission:

ScopeWhy gbx needs it
https://www.googleapis.com/auth/drive.appdataTo store one encrypted file, gbx-sync.bundle, in gbx's private application data folder in your Google Drive, and to read it back on your other computers.
  • The file contains only your gbx configuration (provider settings and tokens), encrypted with AES-256-GCM.
  • gbx cannot see, open or change any other file in your Drive, and does not request your name, email address or profile.
  • Google user data is not sent to the gbx developers, to any AI model or to anyone else. It is never used for advertising or to train AI or machine-learning models.
  • gbx does not use Google APIs to generate or process images, and never for AI-generated non-consensual intimate imagery (NCII) or any other sexual content.
  • Delete the synced data with gbx cloud logout --delete-remote --yes. Revoke access with gbx cloud logout --revoke or at myaccount.google.com/permissions.

gbx's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Full details are in the Privacy Policy.
